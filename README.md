# Pre-entrega 4 | Al Automation Avanzado
El proyecto de automatización de tareas mediante la plataforma de n8n.

## Descripción
Workflow creado como parte de la formación en IA y Automatización Avanzada. Integra inteligencia artificial, n8n y servicios externos para gestionar consultas comerciales, organizar información y mejorar la atención al cliente.

## Tecnologías utilizadas
**N8N:**  el diseño y coordinación de workflows.
**Groq:** Procesamiento de consultas y generación automática de respuestas mediante modelos de lenguaje (LLM).
**Gmail:** Gestión de correos electrónicos y generación automática de borradores de respuesta.
**HubSpot:** Gestión de contactos: búsqueda, creación y actualización de información.
**Slack:** Notificaciones internas para la automatización.
**Airtable:** Almacenamiento y recuperación de información mediante memoria persistente.

## Funcionalidades principales
- Recepción y clasificación automática de consultas.
- Distribución de solicitudes mediante el sistema Triage.
- Validación de datos y filtrado de correos promocionales y automáticos.
- Búsqueda de contactos en HubSpot para evitar duplicados.
- Creación y actualización automática de contactos.
- Generación de respuestas comerciales mediante inteligencia artificial.
- Creación de borradores en Gmail para revisión y aprobación humana.
- Notificaciones automáticas al equipo mediante Slack.
- Gestión de memoria conversacional temporal y persistente mediante IA.
- Derivación de solicitudes a flujos de trabajo especializados.
- Procesos de auditoría y gestión de errores
